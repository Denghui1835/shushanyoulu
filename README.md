# 书山有路

> 课程的 GitHub，加上听读一体。
> 人人可以做一门自己的课，愿意开源就开源；走路、通勤、睡前都能听，听的时候还能跟着原文走。

**当前状态：P1 进行中**。备考线已建成；听读线正在做原文逐句朗读与逐句高亮；书山 Hub 的广场、发布、一键学习已有骨架。

## 一句话

**供给侧：书山 Hub 是课程的 GitHub。**

人人可以用它做一门自己喜欢的课，上传托管；愿意开源就开源，不愿意就私有；想找人一起改，就拉协作者，把一门课改到臻于至善。

**消费侧：听读一体，听带读。**

走路、通勤、睡前都能学。**听是主线，但听的时候能跟着原文走**——不至于听个热闹。

| 学习方式 | 爽（不痛苦） | 真正受益 |
|---|---|---|
| 抖音式短视频 | 是 | 否：刷完就忘 |
| 课本 | 否：读起来痛苦 | 是 |
| **书山有路** | **是：听着不痛苦** | **是：跟着原文，学得进去** |

我们不做好坏判断，只承认一个事实：**能被坚持的学习方式才有用**。
短视频的问题不是短，是注意力离开了要学的东西；课本的问题不是深，是读起来太费劲。

## 听读：三种形态，用户自选

| 形态 | 音频内容 | 与原文对齐 | 需要模型 | 定位 |
|---|---|---|---|---|
| `read` | 原文逐句朗读，一字不改 | 逐句高亮，来自分句本身 | 否 | 最忠实，先落地 |
| `narrate` | 讲书人口语化改写（段级） | 模型插入锚点，失败时模糊回退 | 是 | 主线默认 |
| `dialogue` | 双主播对谈（复用现有播客能力） | 段级加锚点 | 少量 | 节目化副产品 |

有个取舍要说清楚：双主播对谈是「另一个人替你消化」——听着爽，但**注意力离开了原文**，
与「能跟着原文」天然冲突。所以单人讲书才最容易做到听是主线、读跟着走。
顺序是 `read` 先落地 → `narrate` 做主线默认 → `dialogue` 作为节目线保留。

**时间轴精度**：段／句级 ±100–300ms。走「逐段实测」而不是按字数分摊——
provider 无关、零新增依赖，而且段间不累积漂移。

## 免费与开源：这件事怎么活下去

**所有课程内容免费听、免费学；代码开源。**不设会员，不设付费墙。

**算力自带——这是最关键的一条约定：我们只开发框架，不承担模型算力。**

- 用户可以配置自己的模型接口，配好之后所有智能功能走他自己的额度，不消耗平台的
- 也可以完全本地运行，数据留在自己电脑上——本项目本来就是本地优先的单库结构，天生适合各自装一份
- 平台只负责把「怎么用」做顺，不负责替谁付钱

这条同时解决两个问题：**可持续**（没有无限补贴的窟窿）与**可信**（数据在你自己机器上）。

冷启动需要内容，所以官方出一门预置精品课。音频按内容寻址缓存，**全局只合成一次、N 个人听同一份**，
成本不随人数线性上涨。官方只出这一份，剩下的靠作者。

> **我们不出算力，我们出的是那套让别人愿意把课放上来、愿意一起改、改了别人还能直接听的框架。**

## 技术

```
前端    React + Vite + Ant Design (:5173)   ｜   Expo / RN 移动端
                              ↓  HTTP / SSE
服务    FastAPI + SQLAlchemy (async)   (:8000)
                              ↓
数据    SQLite（本地优先，WAL）
                              ↓
模型    LLM：用户自带接口（DeepSeek / Claude / OpenAI / Ollama）
        TTS：edge-tts（默认，免费免 Key）/ 豆包 / Azure
```

**听读管线**：

```
Document → 取阅读单元 → 拼整章文本
  ├ read    ：分句 → 分组（每段不超过 180 字）→ 逐段合成 → 实测时长 → 逐句时间轴
  ├ narrate ：按块切分（约 3500 字）→ 每块一次模型调用（口语讲稿 + 锚点）→ 拼装
  └ dialogue：生成播客文稿 → 解析轮次 → 合并 → 合成
```

**三级复用**（预置精品课只花一次钱的技术保证）：

1. 同一仓库同一讲重新生成时命中文稿指纹，直接复用文稿
2. **全局音频去重**：音频按内容寻址存放，预置课只生成一次、N 人共享
3. 跨仓库相同源文本命中文稿指纹，连模型也只跑一次

## 跑起来

```bash
# 前置：Python 3.10 以上、Node 18 以上
# 复制 backend/.env.example 为 .env，填入你自己的模型接口
start.bat
```

后端默认监听 8000（uvicorn --reload），前端默认 5173（vite）。

> ⚠️ 公开部署必须把 `allow_anonymous_local` 置为 `False`，
> 否则未登录请求会拿到 `local_user`（即主人）的全部数据。开发／单机默认为 `True`。
