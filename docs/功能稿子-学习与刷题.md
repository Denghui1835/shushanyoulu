# 书山有路 ·「学习 + 刷题」完整功能稿子

> 版本：v1 · 2026-08-13
> 来源：以用户身份完整走查「伴学首页 → 书架 → 课程书 → 深度教学 → 刷题 → 全真模拟」全流程后整理。
> 目标：作为「AI 主动伴学 + 计算机二级备考」产品的完整功能规格，逐条对应落地到书山有路。

---

## 一、产品定位

**书山有路 = 一本会陪你学习、教你、考你的「活书」。**

核心主张：不满足于「资料堆积」，而是像一个私教一样
——**带节奏（计划）→ 从零讲（深度教学）→ 用题考（刷题）→ 模拟测（全真模拟）→ 查漏补缺（错题本/统计）**。

## 二、信息架构

```
书山有路
├── 📚 学习
│   ├── 伴学首页（小书虫 AI 对话 + 元气值）
│   ├── 我的书架（课程书 = 一切学习的入口）
│   │   └── 一本书内：阅读 / 深度教学 / 刷题练习 / 播客 / 全真模拟（按书聚合）
│   ├── 我的计划（AI 生成计划表）
│   ├── 计划表（手动周计划）
│   └── 学习统计（答题/打卡/元气）
├── 🌐 社区（作品广场：收藏 / Fork / 提建议）
└── 👤 我的（个人中心）
```

**设计原则：学习工具收进「书」里，侧边栏只留入口与全局页。**

## 三、核心用户旅程（零基础 → 考试）

1. **选书**：书架里挑一门课（如《计算机二级 · Python》）。
2. **开课**：书内「🧰 学习工具」→「深度教学」，从零讲每个考点（讲→考→判→评）。
3. **练**：学完考点 →「刷题练习」，先客观题（选择/填空）练手感。
4. **复盘**：做错的题「加入错题本」；AI 阅卷给点评。
5. **测**：学完 2~3 周 →「全真模拟」限时考试，看成绩单。
6. **冲刺**：考前刷「真题·操作题」+ 错题本 + 统计查漏。

## 四、功能模块详解

### 1. 伴学首页
- 小书虫 AI 对话（语音/文字），有伴学人设。
- 元气值激励：每次学习/打卡/答对攒元气值，可见可累积。
- 每日打卡。

### 2. 我的书架（课程书体系）
- 每门课 = 一本书；书内组织章节（可分组/整书导入 PDF 自动分章）。
- 书有三级分类：门类 → 一级学科 → 书（如 工学 → 计算机科学与技术 → 二级备考书）。
- 书内「🧰 学习工具」栏：深度教学 / 刷题练习 / 播客 / 全真模拟（按书内容智能显示）。
- 支持导入/导出整书（.yqp）、社区公开/收藏/Fork。

### 3. 书内学习工具
- **深度教学**：按书学科预选考点，AI 从零讲→考→判→评。
- **刷题练习**：落到本书第一个题库章节。
- **播客**：只看本书章节生成的 AI 播客（可听/重生成）。
- **全真模拟**：仅当本书含题库章节时出现，按书科目路由到对应模拟卷。

### 4. 深度教学（讲 → 考 → 判 → 评）
- 大白话 + 生活化比喻讲一个考点。
- 讲完出一题开放思考题，学习者作答。
- AI 判断对错：答对肯定+追问，答错共情+指错+引导。
- 默认 6 轮，可中途结束；每次记 StudyLog 攒元气。
- 考点目录按「门类→学科→知识点」三级，零基础可「点菜式」选学。

### 5. 刷题练习（客观题优先）
- **出题只出客观题**（选择题 + 填空题），不生成简答题；选择题答案唯一、6 选项。
- 作答即判：选择题精确匹配（支持字母 A-D 与选项全文），填空/简答 **AI 阅卷点评**。
- 题目管理：弃用/恢复（软删除）、加入错题本。
- 错题本：跨书聚合，考前集中复习。
- 章节维度：每个章节有题即可刷，顶部下拉切换资料。

### 6. 全真模拟（严格对齐真实考试）
- **科目化**：Python（基本操作3×5+简单2×12.5+综合1×20）与 C（填空3×6+改错2×9+设计1×24）。
- **限时**：120 分钟倒计时，最后 5 分钟变红，到时自动交卷。
- 试卷结构严格：选择 40 分 + 操作 60 分；合格线 60。
- 交卷确认（提示未答数）→ 成绩单：总分/各部分得分/合格与否/逐题解析。
- 操作题按「思路重合率」给步骤分；进模拟前有考试规则说明页。

### 7. 学习计划
- AI 一键生成计划表：选课程考点 → 选时段 → 定每日投入 → 生成天级任务。
- 手动计划表：按天/时段排学习任务，可标记完成、定时通知。

### 8. 学习统计
- 答题正确率、打卡记录、元气值成长、学习动态流。

## 五、内容体系（题库/真题/课程书）

| 类型 | 来源 | 说明 |
| --- | --- | --- |
| 深度教学考点 | 内置 CURRICULUM | 每科 14+ 考点，LLM 生成教学卡 |
| 精编题库 | 课程书种子 | Python 40 选择 + 10 操作；C 40 选择 + 9 操作 |
| **真实真题** | 从练习软件提取（题面） | Python 17 道操作真题，答案加密、AI 阅卷 |
| 备考路线书 | 课程书种子 | 备考总纲 + 第 1~5 周逐日计划 |
| 社区课程 | 用户创作 | 广场分享、收藏、Fork、提建议 |

## 六、激励与留存
- 元气值：学→攒；答对→攒；打卡→攒。
- 错题本：错误沉淀为复习素材。
- 连续学习节奏：AI 计划表保证「每天学一点」。
