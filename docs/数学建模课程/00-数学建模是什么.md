# 数学建模是什么（零基础版）

## 一句话定义

**数学建模 = 把现实问题翻译成数学，算出结果，再翻译回现实。**

它不要求你"数学多厉害"，而是要求你会**把问题说清楚、简化到能算、算完敢用**。评委看的不是你用了多高深的公式，而是你的模型是否**贴合题目、逻辑自洽、结论可信**。

## 你天天都在用数学建模

- **外卖路线**：平台给你规划"最快到达路线"，背后是最短路问题。
- **天气预报**：用过去的数据预测明天，是预测模型。
- **游戏平衡**：角色的伤害数值怎么定才不超模，是最优化问题。
- **奶茶店定价**：卖贵了没人买，卖便宜不赚钱，怎么定？这是"目标 + 变量 + 约束"的优化模型。

你其实已经会建模了，只是没意识到。比赛要做的，就是把这套直觉**写成规范的数学语言和论文**。

## 数学建模和数学课的区别

| 数学课 | 数学建模 |
|---|---|
| 题目条件齐全，答案唯一 | 条件模糊，要自己补假设 |
| 只要"做对" | 要"解决问题 + 讲清楚理由" |
| 答案对就满分 | 过程、逻辑、表达、创新都算分 |
| 单人闭卷 | 三人 72/96 小时，工具随便用 |

建模没有标准答案，但有**好坏之分**：好的模型经得起检验、说得清假设、能给决策者用。

## 建模的三个动作

1. **翻译**：把题目里的自然语言变成数学对象——哪些是已知量，哪些是要求的目标，哪些关系可以写成式子。
2. **简化**：现实太复杂，先做合理假设（比如"先不考虑天气"），把问题缩到能算的规模。
3. **算**：用公式、软件或代码求解，最后把数字翻译回"老板听得懂的话"。

记住这三步，你就握住了建模的主线。后面所有模型，都是在这三步里换工具而已。

## 零基础完全不用怕

比赛真正高频用到的数学只有几样：

- **代数与函数**：设变量、写关系式（几乎每题都有）。
- **概率统计**：描述数据、估计参数、做预测（B 类题常客）。
- **简单的优化**：线性规划、整数规划（会调库就行）。
- **一点点矩阵**：层次分析、聚类、图论会用到，会用工具即可。

编程部分，**能读、能改、能跑通示例代码就够了**，不需要当程序员。绝大多数队伍的代码是"抄底子 + 改参数 + 补注释"。

## 比赛到底考什么

评委手里的打分表通常围绕四件事：

1. **模型合理性**：假设是否清楚，模型是否对题（占分最重）。
2. **求解与检验**：算没算出来，结果是否经过检验，有没有误差/灵敏度分析。
3. **论文表达**：摘要能不能 5 秒抓住人，图表是否规范，逻辑是否通顺。
4. **创新与工作量**：有没有自己的思考，是否做了别人没想到的角度。
