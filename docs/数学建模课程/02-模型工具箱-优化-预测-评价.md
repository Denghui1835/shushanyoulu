# 模型工具箱：优化 · 预测 · 评价

比赛七成题目可以归进三类：**找一个最优方案（优化）、猜一个未来（预测）、比一堆方案（评价）**。每个模型记住"一句话是什么 + 什么时候用 + 最小例子"就够了。

## 一、优化模型：怎么算最划算

**是什么**：在"能改的"（决策变量）和"不能违反的"（约束）之间，找出让"目标"最好的一组取值。

**什么时候用**：题目出现"最大/最小/最优/成本最低/利润最高/排班最少"。

**最小例子**：

> 奶茶店卖两种茶：A 利润 3 元/杯，B 利润 5 元/杯；每天原料最多做 100 杯，A 最多卖 60 杯，B 最多卖 50 杯。怎么排产量利润最大？

写成模型：

```
目标：max  3x + 5y
约束：x + y ≤ 100
     0 ≤ x ≤ 60
     0 ≤ y ≤ 50
     x, y 为整数
```

这题靠直觉就能答（全做 B，再做 A），但题目一复杂，直觉就失效了——这时候用线性规划求解器，几秒钟出结果。

## 二、预测模型：怎么猜未来

**是什么**：根据历史数据找规律，外推未来。

**什么时候用**：题目给"几年/几个月的数据表"，让你预测下一年/下一月，或让你评估"某因素对结果的影响"。

**三步走**：

1. **先画图**：把数据点描出来，看趋势是直线、曲线还是周期性。
2. **再选法**：线性趋势用最小二乘；非线性用多项式/指数；分类预测用 Logistic 回归；规律复杂可用机器学习（但要说明样本量）。
3. **最后验**：留一部分数据不参与拟合，用它们检验预测误差（平均绝对误差、均方根误差）。

**陷阱**：数据量很少时（比如只有 5 个点），再漂亮的曲线都是"过拟合"，评委一眼就看穿。宁可用简单模型 + 合理误差区间。

## 三、评价模型：一堆方案选哪个

**是什么**：多个方案/对象，多个维度，怎么排个高低。

**什么时候用**：题目出现"综合评价""选择最优方案""排名""满意度评估"。

**AHP 层次分析法（最常用，最容易上手）**：

1. 定准则：比如选旅游目的地，看"费用、风景、交通、美食"四个维度。
2. 两两打分：准则两两比较，1~9 标度（1 同样重要，9 极端重要）。
3. 算权重：构造判断矩阵，算特征向量归一化 → 每个维度的权重。
4. 一致性检验：CR < 0.1 才可信；不通过就调整打分。
5. 加权求和：每个方案在各维度的得分 × 权重，总分排序。

**提醒**：AHP 的"1~9 打分"有主观性，论文里要诚实说明，最好再配一个客观方法（比如熵权法）交叉验证。

## 怎么选模型：一张流程图

```
题目要"最优方案"？  → 优化模型
题目要"预测未来"？  → 预测模型
题目要"比高下/排序"？ → 评价模型（AHP/熵权/TOPSIS）
题目要"算概率/风险"？ → 蒙特卡洛/概率模型
题目要"找关系/分组"？ → 图论/聚类/回归
```
