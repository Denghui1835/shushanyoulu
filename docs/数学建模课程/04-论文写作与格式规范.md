# 论文写作与格式规范

比赛是**先看论文、再谈模型**。一份"模型 70 分、论文 30 分"的论文，常常输给"模型 60 分、论文 90 分"的论文。因为评委没有时间替你找亮点。

## 一、格式红线（硬性要求）

这些是**一票否决或大幅扣分**的雷区，交卷前逐条检查：

- 承诺书、编号页：按赛区要求填写，不得泄露学校/姓名（部分赛事匿名）。
- 摘要页：**一页以内**，超页直接重灾区。
- 正文页码、字体、行距：按官方模板。
- 附录代码：必须可运行、有注释，文件按题目命名。
- 引用：数据、方法、图片来源要标注，严禁直接照搬他人论文。

## 二、摘要 = 命根子

评委先读摘要，读懂了才愿意看正文。写法固定成模板：

> 针对问题一，建立 **XX 模型**（方法名，越具体越好）。首先……（一句关键处理）；其次……（一句求解方法）；最终求得 **X = 3.42**（关键数字），并通过 **YY 检验**验证了模型的稳定性。

规则：

- **每问一段**，一问不漏。
- 每段出现"**模型名 + 方法 + 关键数字 + 一句结论**"。
- 全文摘要控制在 800~1000 字，不许出现"本文……大概……"这类废话。

## 三、正文骨架（先结论后过程）

1. **问题重述**：不是抄题！用两三段证明你读懂了：背景、要解决什么、难点在哪。
2. **问题分析**：每题一段"我打算怎么做、为什么这样做"——这是评委判断你思路的地方。
3. **模型假设与符号说明**：假设逐条编号；符号用三线表列出。
4. **模型建立**：每题一小节，公式编号，变量解释紧跟公式。
5. **模型求解**：算法步骤 + 结果表格；图表放正文，代码放附录。
6. **模型检验**：误差分析 / 敏感性分析 / 与真实数据对照。
7. **模型评价**：优点（2~3 条）、不足（1~2 条，诚实写）、改进方向。
8. **参考文献 + 附录**。

## 四、图表规范（证据比文字有力）

- **图**：矢量图（导出 PDF/SVG），坐标轴带单位和图例，一图一个结论，图下配一句说明。
- **表**：用三线表（顶线、栏目线、底线），表头清晰，数据保留合理位数。
- 图表编号与正文交叉引用："如图 3 所示，……"。
- 常见扣分点：截图模糊、图例缺失、单位缺失、表格是截图贴的。

## 五、给模型起"体系化名字"

不要写"模型一、模型二"，要写：

- "基于**灰色预测 GM(1,1)** 的销量预测模型"
- "基于**层次分析法与熵权法组合赋权**的综合评价模型"
- "基于**改进模拟退火算法**的路径优化模型"

名字里带上方法，评委扫一眼就知道你用了什么、工作量在哪。

## 六、交卷前 30 分钟检查单

- [ ] 摘要一页、每问一段、有数字
- [ ] 正文公式编号、图表编号齐全
- [ ] 附录代码可运行（逐题跑一遍）
- [ ] 承诺书/编号/页码无误
- [ ] 结论与摘要数字一致
- [ ] 参考文献格式统一
