# 备赛 4 周作战计划

以 2026 美赛/国赛为目标，按"**第 1 周打基础 → 第 2 周建工具箱 → 第 3 周真题实战 → 第 4 周模拟冲刺**"推进。每天 1~1.5 小时，周末加练。

## 第 1 周：打基础（别碰真题）

- 读完本课程前 3 章：建模是什么、六步流程、模型工具箱。
- 跑通 Python 三个例子（优化 / 预测 / AHP），每个都改参数重跑一遍。
- 任务：用"奶茶店"自己编一个优化题并求解，发群里互相检查。
- 产出：一台装好环境（Python + numpy + scipy + pulp + matplotlib）的电脑。

## 第 2 周：建工具箱（每个模型一个"底子"）

- 每类模型沉淀一个**可复用脚本**：线性规划、多项式拟合、AHP、蒙特卡洛、K-means。
- 学会两件事：**读数据**（Excel/CSV → DataFrame）、**画规范图**（带标签的折线/柱状/散点）。
- 阅读 1~2 篇 O 奖论文的"模型建立"部分，把它们的骨架抄进自己的模板。
- 产出：个人"模型库"文件夹 + 论文 LaTeX/Word 模板。

## 第 3 周：真题实战（一道题打满 48 小时）

- 选 1~2 道近年真题（本书「真题精读」章节），**完整走一遍六步**。
- 时间分配按比赛比例：审题+分析 3h，建模 12h，求解 12h，论文 18h，机动 3h。
- 重点练"**卡住怎么办**"：模型解不出来 → 简化假设；数据缺失 → 合理插值并说明。
- 产出：一篇完整论文 + 可运行代码，交队友互评。

## 第 4 周：模拟冲刺（完整彩排）

- 周末做一次**全真模拟**：按比赛时长（国赛 72h / 美赛 96h），到点必须交。
- 复盘清单：
  - 审题有没有漏条件？
  - 求解卡了多久？下次怎么提前规避？
  - 论文最后 6 小时够不够？摘要写了多久？
  - 图表规范吗？代码能直接跑吗？
- 把"模拟中发现的问题"转成"比赛时的动作清单"，贴到工位上。

## 队伍分工（三个人三条线）

| 角色 | 职责 | 关键技能 |
|---|---|---|
| 建模 | 定假设、选模型、写公式 | 思路清楚、会查文献 |
| 编程 | 实现求解、画图、出结果 | Python 熟、能调库 |
| 写作 | 摘要、正文、图表、排版 | 会讲故事、手快 |

**注意**：写作不是最后三天才开始的。从第一天起，建模的要给写作的人"一句话模型说明"，编程的要给"图表底稿"——论文是**同步生长**的，不是最后拼出来的。

## 赛程时间分配（96 小时美赛版）

| 时间段 | 任务 |
|---|---|
| 第 1~6 小时 | 选题、读题、定问题分析框架 |
| 第 6~36 小时 | 建模 + 求解第一版 |
| 第 36~60 小时 | 深挖 + 检验 + 敏感性分析 |
| 第 60~90 小时 | 写论文（摘要最后写，但要早起草） |
| 第 90~96 小时 | 检查格式、跑代码、统一图表、交卷 |

**铁律：最后 6 小时只做检查和排版，绝对不新建模型。**
